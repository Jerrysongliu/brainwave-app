# Drop your audio here

Put downloaded MP3s (or WAV/OGG/FLAC — I'll convert) in these folders, then
tell me "done" and I'll loudness-match, trim, rename, wire them into the app,
and add credits.

## Soundscapes  →  incoming/sounds/
Name each file with the scene it's for (anything after the prefix is ignored):

    rain-cozy.mp3
    storm-distant.mp3
    ocean-*.mp3   fire-*.mp3   forest-*.mp3   night-*.mp3   river-*.mp3

If it's a NEW scene type (not rain/storm/ocean/river/fire/forest/pond/night),
just say so and I'll add it.

## Music  →  incoming/music/
Name each with the genre:

    lofi-*.mp3    ambient-*.mp3    classical-*.mp3    piano-*.mp3

## License (important)
For each file, jot the source + license in `sources.txt` here, e.g.:

    rain-cozy.mp3   — Pixabay (Pixabay Content License, no attribution)
    lofi-foo.mp3    — Freesound, CC0
    classical-x.mp3 — Musopen, Public Domain

CC0 / Public Domain / Pixabay → no attribution needed (but I'll log the source).
CC-BY / CC-BY-SA → attribution required; I'll add it to the in-app credits.
Skip anything "non-commercial only" or unclear — can't ship those to the App Store.
